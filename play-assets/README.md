# Play Store listing assets

Generated 2026-08-25 for the first closed-testing submission.

| File | Use | Spec |
|---|---|---|
| `play-store-icon-512.png` | Store listing icon | 512×512, generated by bubblewrap from the web manifest |
| `play-feature-graphic.png` | Feature graphic | 1024×500, centre-cropped from `public/og.png` |
| `play-screenshot-1.png` | Phone screenshot | 1080×1920 (9:16) |
| `play-screenshot-2.png` | Phone screenshot | 1080×1920 (9:16) |
| `play-screenshot-3.png` | Phone screenshot | 1080×1920 (9:16) |

Screenshots were captured from the Android emulator (`adb exec-out screencap`)
at 1080×2400 and cropped to 1080×1920, dropping the system status bar. **The
crop matters**: Play is strict about screenshot aspect ratio, and a raw 20:9
phone capture is taller than the allowed range.

To recapture after a UI change, boot the AVD, then:

```bash
adb exec-out screencap -p > shot.png
```

and crop to 1080×1920 starting at y=110.

The feature graphic's title sits fairly close to the top edge because it is
cropped from the link-preview card. Play crops this image further on some
surfaces — if it ever looks clipped in the Console preview, regenerate it from
`tools/og-card.svg` with more padding rather than re-cropping `og.png`.
